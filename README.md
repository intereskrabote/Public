# Финансовый калькулятор

Консольное приложение на Python для решения типовых финансовых задач.

## Возможности

### 1. Кредитный калькулятор
- **Аннуитетные платежи** — равные ежемесячные выплаты
- **Дифференцированные платежи** — убывающие платежи с подробным графиком
- Расчёт: ежемесячный платёж, общая сумма выплат, переплата, эффективная ставка
- Опционально: дата первого платежа для построения графика

### 2. Депозитный калькулятор
- Капитализация: ежемесячно, ежеквартально, ежегодно
- Опциональное ежемесячное пополнение
- Учёт инфляции для расчёта реальной доходности
- Вывод: итоговая сумма, начисленные проценты, реальная доходность

### 3. Инвестиционный калькулятор
- Сложный процент с регулярными ежемесячными взносами
- Расчёт итогового капитала, суммы взносов и инвестиционного дохода
- Горизонт планирования в годах

### 4. Расчёт NPV и IRR
- Чистая приведённая стоимость (NPV) по денежным потокам
- Внутренняя норма доходности (IRR) методом Ньютона
- Поддержка произвольного количества периодов

### 5. Конвертер валют
- Актуальные курсы через API (exchangerate-api.com)
- Автоматическое переключение на офлайн-курсы при отсутствии интернета
- Поддержка основных валют: USD, EUR, RUB, GBP, CNY, KZT и др.

## Требования

- Библиотека `requests` (для конвертера валют)

## Формулы

### Аннуитетный платёж
```
P = S × (r × (1+r)^n) / ((1+r)^n - 1)
где:
  S — сумма кредита
  r — месячная ставка (годовая / 12 / 100)
  n — срок в месяцах
```

### Дифференцированный платёж
```
Основной долг = S / n
Проценты = Остаток × r
Платёж = Основной долг + Проценты
```

### Сложный процент с пополнениями
```
FV = P × (1 + r/n)^(n×t) + PMT × [((1 + r/n)^(n×t) - 1) / (r/n)]
где:
  P — начальный капитал
  PMT — ежемесячный взнос
  r — годовая доходность
  n — количество капитализаций в год (12)
  t — срок в годах
```

### NPV
```
NPV = Σ(CF_t / (1+r)^t) - Initial Investment
```

### IRR
Расчитывается итеративно методом Ньютона-Рафсона.
